# 强度匹配的 JET 区域强迫：图的目的与逻辑位置

## 主比较

研究对象限定为 150 h 前仍在增强的四对状态：J72/C74、J84/C101、J96/C138、J108/C142。它们满足预先声明的条件：最低层轴对称最大切向风差不超过 1 m/s、RMW 差 0–3 km、中心气压差不超过 2.6 hPa，且两者 6 h 风速倾向均为正。完整数值见 `matching/strength_matched_pairs.csv`。

匹配不能消除所有历史差异，却避免把“JET 已经更强、半径已经更小”直接误读成急流强迫。因此它在逻辑链中位于“强度差异”之前：

\[
\text{JET 环境与相互作用}
\rightarrow \text{外区/内区强迫或结构}
\rightarrow \text{SE 平衡环流}
\rightarrow \text{内核动量与加热倾向}
\rightarrow \text{随后强度差异}.
\]

## 每幅图解释什么

`se/matched_jet_region_eddy/J072p0_C074p0_eps1e-04.png` 的九个面板按行阅读。

1. **左上**：匹配对的状态直接诊断涡动切向加速度差 `F_lambda,eddy(JET)-F_lambda,eddy(CTRL)`。它是物理源，单位为 m s-2，不是 SE 方程中的最终右端。
2. **中上**：同一源经固定 CTRL 基本态映射后的完整 SE RHS；这一面板才是平衡方程接收的强迫。
3. **右上**：只保留外上层 `r>=600 km, 8<=z<=18 km` 的已组装 RHS。它是“JET 区域源支持”实验，目的是问：如果只让外上层 JET 环境附近的 eddy RHS 作用，内核能出现多少平衡响应？它并不对原始通量硬截断，因此不会把窗口导数伪装成物理力。
4. **中排**：完整、外上层与内核 RHS 分别投影出的 `Delta u_r`。它回答直接 eddy 强迫能否改变低层入流和内核径向环流。
5. **下排**：同三种 RHS 对 `Delta w` 的投影。它回答外上层源是否可远程触发/改变内核上升。

所有区域响应在同一个固定 CTRL 非均匀网格 SE 算子上求解，因此“外上层 + 内核 + 剩余区域 = 全域响应”是可检验的线性恒等式，而不是主观的贡献百分比。

## 当前结果能说明和不能说明什么

在四对匹配状态中，外上层盒的非轴对称风速相对 CTRL 增加 `1.17–1.74 m s-1`（RMS 增加 `1.29–2.07 m s-1`），因此这个盒确实包含 JET 试验的环境风扰动。可是，该盒的 RHS L2 范数仅占完整 direct-eddy RHS 的约 `1.4e-5` 至 `2.0e-5`；其对低层入流和内核上升响应的投影也接近零。相反，内核 RHS 几乎重构全域 direct-eddy 响应。

因此，**当前数据不支持“外上层急流区域的直接涡动切向力，通过 SE 远程驱动内核增强”作为早期增强的主路径**。这不等于 JET 不重要。`JET−CTRL` 的 eddy 强迫包含三类无法仅靠这两个试验拆开的成分：施加急流本身、急流–台风相互作用、以及台风对急流的非对称响应。因此此处应称为“JET 试验诱发的强迫”，不能称为纯净的 imposed-jet forcing。

若随后证实外上层非轴对称风速在该盒显著增强、但其 eddy RHS 仍小，则更合理的竞争链条是：JET 先改变切变、对流非对称性、加热位置或基本态，再由这些内核变化影响强度；而不是外区 torque 的直接遥作用。下一步需要在这四对中检验该条件，并将加热位置与内核切向风倾向放在相同匹配框架中。
