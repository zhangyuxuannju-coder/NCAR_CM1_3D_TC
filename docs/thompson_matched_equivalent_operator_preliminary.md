# Thompson：强度匹配的等效算子强迫初步结果

## 问题与比较设计

目标是检验 150 h 前 JET 试验的较快增强是否可以由 SE 左端基本态改变解释，而不把不同气旋强度本身误读成“急流效应”。因此使用四个事先确定的增强期匹配对：JET 72/CTRL 74 h、JET 84/CTRL 101 h、JET 96/CTRL 138 h、JET 108/CTRL 142 h。配对同时限制最低层轴对称切向风、RMW、中心气压和 6 h 增强率；完整残差见 `matching/strength_matched_pairs.csv`。

这仍不是完全相同的涡旋历史，只是削弱了当前强度和尺度造成的混杂。因此它位于证据链的第二环：**先证明比较的是近似相同强度的增强状态，再问基本态算子是否不同**。它不能单独证明外加 jet 的因果性。

## 定义与可比性

主结果不再把三个旧分量直接当作完整算子差异，而是用同一非均匀网格上的实际离散矩阵计算

$$S_{op,lead}=-(L_J-L_C)\psi_{CC}.$$

这里 $\psi_{CC}$ 是 CTRL 算子在 CTRL **直接涡动切向力矩** RHS 下的平衡解，$L_C,L_J$ 分别包含各自的正则化 $K_1,K_2,K_3$ 及 $1/(\rho r)$。选用该受控参考 RHS 的原因是已验证原始 CM1 `ub/vb` 逐时输出是输出步的 Runge--Kutta 快照，而非时段平均，不能闭合状态倾向；所以本结果是 **balanced operator projection with direct-eddy reference**，不是完整 CM1 预算的 SE 归因。

同时保存此前构建的连续系数型分解：

$$S_A=-\partial_r(\Delta K_1w_{CC}),\quad S_I=\partial_z(\Delta K_3u_{CC}),$$

$$S_B=-\partial_r(\Delta B u_{CC})+\partial_z(\Delta B w_{CC}),\quad \Delta B=-\Delta K_2.$$

它们的和 $S_{ABC}$ 是旧诊断的可追溯版本。$S_{op,lead}-S_{ABC}$ 被标为“度量/离散化余项”：它含 $1/(\rho r)$ 差异和离散通量形式差异，没有独立物理归因。

精确的有限差异检验为

$$L_C(\psi_{JC}-\psi_{CC})=-(L_J-L_C)\psi_{JC}.$$

它检验一阶近似是否足够，不是新的强迫项。

## 图的作用和逻辑位置

每个匹配对在 `se/matched_equivalent_operator/` 中有一张默认正则化 $\epsilon=10^{-4}$ 的 3×4 图。

1. 第一行前三幅为 $S_A,S_I,S_B$，第四幅为其和。它回答“此前的三个等效算子项各自位于哪里、符号怎样、是否相互抵消”。这是**机制候选的分解环**，不能代表完整算子。
2. 第二行左一为离散 $S_{op,lead}$，中间为它减去旧三项之和的余项，右一仅保留 $r\ge600$ km、$8\le z\le18$ km 的 jet 区源区。它回答“旧分解能否重构真实离散算子差异”以及“jet 区的算子差异在 RHS 范数中有多少”。这是**算子一致性和源区定位环**。
3. 第二、三行右侧的 $\delta u_r,\delta w$ 是对完整一阶 $S_{op,lead}$ 和 jet-box 支持部分的 CTRL SE 响应。它回答“即使在 jet 区存在算子差异，它能否投影到内核低层入流和内核上升”。这是**从外侧 jet 区走向内核次级环流的传递环**。
4. 最后一幅 exact operator RHS 与一阶解的误差指标配合使用。它回答“一阶把算子差异移到 RHS 的近似是否可用”。若误差很大，前面分项只能用于形态描述，不能用于定量机制排序。

例如 J72/C74 的图为 `J072p0_C074p0_eps1e-04.png`：jet-box 强迫确实位于上对流层外侧，但对内核低层入流和内核上升的投影分别只有 $8.6\times10^{-6}$ 和 $4.1\times10^{-5}$，而完整一阶算子响应主要由内核/近内核算子差异控制。

## 数值结果：默认正则化 $\epsilon=10^{-4}$

所有矩阵相对残差为 $1.2$--$2.3\times10^{-15}$，所以以下限制来自物理近似和正则化，而不是线性方程未解出。

|匹配对|jet-box $S_{op,lead}$ RHS L2 占比|jet-box 对内核低层入流投影|jet-box 对内核上升投影|一阶/精确响应误差|二阶 RHS 占精确 RHS|
|---|---:|---:|---:|---:|---:|
|J72/C74|$1.67\times10^{-5}$|$8.55\times10^{-6}$|$4.06\times10^{-5}$|0.44|0.35|
|J84/C101|$8.74\times10^{-6}$|$-4.39\times10^{-6}$|$-9.28\times10^{-8}$|5.40|0.69|
|J96/C138|$1.63\times10^{-5}$|$-3.21\times10^{-6}$|$-2.28\times10^{-7}$|1.34|0.61|
|J108/C142|$7.00\times10^{-6}$|$-9.03\times10^{-6}$|$4.00\times10^{-7}$|1.03|0.29|

这里“投影”是 jet-box 解在指定内核响应上的最小二乘系数；接近零表示该源区的平衡响应几乎不贡献完整一阶算子响应。

三个正则化强度 $10^{-5},10^{-4},10^{-3}$ 下，jet-box RHS 占比始终为 $5.3\times10^{-6}$--$2.7\times10^{-5}$，内核投影始终约为 $10^{-4}$ 以下。因此有一个跨正则化稳定的**否定性结果**：在当前强度匹配和定义的外侧上对流层 jet 区内，等效算子强迫虽存在，但无法解释 150 h 前内核增强的主要平衡环流改变。

相反，一阶近似本身不稳健：J84/C101、J96/C138 和 J108/C142 的一阶/精确响应误差随正则化显著变化，J84/C101 最严重。这些时次不能用 $S_A,S_I,S_B$ 的幅度给出定量排序。J72/C74 的误差较小但仍为 0.39--0.47，也应表述为候选一致性证据，而不是因果证明。

旧三项的和在默认正则化下占离散一阶强迫 L2 范数的 0.70--0.93；但是其重构余项仍为 0.37--0.52。这说明旧图适合展示 $K_1,K_2,K_3$ 相关结构，不能替代完整离散 $S_{op}$。

## 关于“是否由 jet 导致”

jet-box 的定义是强度匹配后 JET-minus-CTRL 基本态算子差异在 $r\ge600$ km、8--18 km 的支持部分。它可以称为 **JET-run-induced jet-region operator contribution**：该区域与施加 jet 的高度/半径范围一致，但其中同时包含施加 jet、jet--vortex 相互作用和涡旋对环境的反馈。它不是“纯外加 jet”的隔离因果效应。

因此目前证据链到这里的结论是：外侧 jet 区确实具有可检测的非轴对称涡动与算子扰动，但其直接平衡 SE 算子通道对内核响应极小。下一环应转向匹配态下的加热位置/加热效率、内核涡动动量输送，或通过固定环境 jet 而重置内核状态的 CM1 敏感性试验隔离因果路径。
