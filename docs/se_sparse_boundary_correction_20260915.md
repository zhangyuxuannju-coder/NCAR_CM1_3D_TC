# SE 稀疏求解边界修正说明

更新日期：2026-09-15。范围：TC_dynamic 的 Bui general SE 稀疏诊断路径。

## 当前状态

当前修正已通过离散算子、边界、风场换算、线性叠加及残差测试，可继续复用为
修改后基本态的平衡诊断。不要仅因 SE 与 CM1 不完全匹配就判定求解算法错误、
重写求解器或调整色标掩盖差异；也不要把内部测试通过表述为已完整再现真实环流。

## 修正内容

实现位于 `src/_se_pipeline_single.py` 的 `solve_se_sparse` 和 `psi_to_uw`。

| 位置 | 原问题 | 修正后 |
|---|---|---|
| 径向两侧混合导数 | 注释称镜像项抵消，但矩阵仍保留部分项 | 镜像条件下混合导数项正确抵消 |
| 外侧一阶径向导数 | 二阶导数用镜像，一阶导数仍用单侧非零差分 | 一阶径向导数为零 |
| 顶部 | 等值虚点与一阶导数置零不对应同一节点的中心差分 | 顶部采用镜像虚点，二阶导数系数同步修正，混合和一阶导数为零 |
| 两侧垂直速度 | 复制内部值，与流函数径向零导数不一致 | 两侧垂直速度为零 |
| 最内侧径向风 | 被独立强制为零，不由流函数换算 | 与其他半径一样由流函数垂直导数计算 |

采用的符号约定是

\[
u_r=-\frac{\psi_z}{\rho r},\qquad w=\frac{\psi_r}{\rho r}.
\]

当前边界为：径向两侧 `psi_r=0`，顶部 `psi_z=0`，底部虚点 `psi=0`。
镜像关系：内侧径向虚点等于第二个径向节点；外侧虚点等于倒数第二个径向节点；
顶部虚点 `P[:,-1]=P[:,-3]`，底部 `P[:,0]=0`。
因此顶部最后一个物理节点 `u_r=0`，两侧 `w=0`。

以上是旧均匀步长稀疏求解器的默认边界。2026-09-16 增加的
`inner_axis_dirichlet=True` 选项将首个存储径向节点 `psi=0`，避免默认内侧
Neumann 条件容许的近轴 `u_r=-psi_z/(rho*r)` 伪大值。新稀疏求解须对完整态和
每个分项一致启用该选项，并重算流函数与风场；它是首节点正则性敏感性，
不是精确 `r=0` 离散。该选项下不能再称内侧边界为 `psi_r=0`。

这不是四边齐次 Dirichlet，也不等同于速度的不可穿透、无切向应力自由滑移。
不要在摘要中把流函数 Neumann 边界直接写成物理自由滑移边界。
本次名义求解域为 0–1200 km、0–20 km，存储节点为 r=6–1194 km、z=0.025–19.75 km；
上述顶部条件施加在最后一个物理节点，不应误称存储网格包含精确的 r=0 或 z=20 km 节点。

## 正确复用结果

只修补边界后，必须重算完整 CTRL/JET 解及各强迫响应，不能把旧 `ctrl_psi`、
`jet_psi` 与修正后矩阵混用，也不能复用旧响应作为新边界结果。
全部算子响应包含 K1/K2/K3 和密度度量变化；单项惯性响应不能替代全部算子变化。
保留高阶／耦合响应及流函数转风速的密度换算项，不把密度换算项冒称为 RHS 强迫。
直接涡动通量已经代表的平流项，不再次加入 RHS 造成重复计数。

内部线性叠加应通过；与 CM1 的比较则关注方向、位置、强度和时间趋势，
不要求近似 SE 等于模式全部实际风场。趋势相似也不是独立因果证明。

## 已知限制

- 原始 z 网格不均匀，当前稀疏求解和风场换算仍使用平均 dz；本次未改垂直离散算法。
- 独立的 `src/se_nonuniform.py:solve_flux_form_dirichlet` 在实际 `r_m/z_m`
  上求解，四个存储边界均为 `psi=0`；其解、边界与本页稀疏路径不能混用。
- 独立 `solve_se_sor` 的径向布局和边界未修改；稀疏路径验证不适用于 SOR。
- 边界修正后，部分早期大响应仍存在；不能宣称异常大值已被边界修正消除。
- 行尺度归一后的矩阵条件数下界估计约 10^5–10^6，仅表示数值敏感性，
  尚不能确定它或任何单一近似是大响应的主要原因。
- 模式流函数对比使用原有 `fit_psi` 运动学重建，并非模式原生流函数变量或 SE 反演。
  缓存采用平均密度×平均风，忽略密度—风协方差；重建失配单独保留。
- 流函数对比使用同一参考点归零，双方都不乘 2pi；统一色标比较幅度，独立色标仅比较结构。
