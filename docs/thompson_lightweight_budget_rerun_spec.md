# Thompson 轻量重跑：可闭合 SE 强迫预算的最小规格

目标是取得可与输出状态增量在同一时间积分定义下比较的热力和水平动量预算。现有 `ub_*`、`vb_*`、`ptb_*` 为写出步的 RK 快照，不能替代此产物。

## 三个优先窗口

| 窗口 | 建议时段 | 目的 |
|---|---:|---|
| 早期增强 | 84–108 h | 检验 JET 内收且更强的加热是否产生更有利的低层角动量倾向。 |
| 转折 | 144–162 h | 检验 JET 从气压优势转为劣势前，何种强迫/结构项首先改变。 |
| 后期落后 | 192–204 h | 检验后期是否存在稳定、可闭合的加热、涡动或边界层强迫差。 |

先选 84–96 h 做一次端到端测试；闭合通过后再跑完整窗口。CTRL 与 JET 必须从各自同一时刻的重启场出发，并保持现有网格、物理、海洋和输出定义一致。

## 预算累积定义

对每一个保存窗口 `[t0,t1]`，在每个外部动力时间步计算 RK 加权后的各项倾向，并累积

\[
\overline{B}_k^{[t_0,t_1]} = \frac{1}{t_1-t_0}\sum_n \Delta t_n B_k(t_n).
\]

端点状态倾向定义为

\[
\frac{X(t_1)-X(t_0)}{t_1-t_0}.
\]

两者必须写入同一 NetCDF 记录，并在属性中记录 `budget_time_semantics = interval_mean_dt_weighted`、窗口端点、实际步数和 `sum_dt`。若使用固定 10 s 步长，也仍保存 `sum_dt`，不可只写名义时间间隔。

## 最小输出集

第一轮只输出全量笛卡尔网格，避免先裁剪再引入边界通量误差：

- 端点状态：`u`, `v`, `th`, `rho`, `prs`，以及网格坐标和时间。
- 总收支闭合项：`u_budget_total_mean`, `v_budget_total_mean`, `th_budget_total_mean`。
- 分项：所有已计算 `ub_*`、`vb_*`、`ptb_*` 的 interval mean；保留不可用项为缺失变量，而不是零填充。
- 诊断元数据：每项名称、单位、RK 阶段约定、是否包含隐式步骤/压力求解/边界条件以及总收支是否覆盖该项。

如存储受限，先只写总收支和 84–96 h 的逐小时端点；总收支在原生交错网格通过后再写分项。不要以每分钟完整三维文件替代步长累积，它仍无法保证预算与状态同一积分定义，且 I/O 代价极高。

## CM1 r20.3 的实现位置

当前源码中，`src/cm1.F` 在每步决定 `doubud/dovbud/dotbud`，`solve1/solve2/solve3` 写入 `udiag/vdiag/tdiag`，`writeout.F` 再直接写出这些数组。轻量版应：

1. 在常规写出之间的每个模式步开启预算计算，但不增加常规 state 写出频率。
2. 在完成该步的 RK 更新后，将 `dt × udiag/vdiag/tdiag` 加到单独的双精度累积数组。
3. 在普通输出时，以 `sum_dt` 归一化累积数组，写成新的 `*_interval_mean` 变量；随后将累积数组和 `sum_dt` 清零。
4. 另写总动力/热力倾向的 interval mean；这项是分项求和遗漏或符号错误的直接闭合基准。

必须保留原始 `ub_*` 等快照变量，作为调试参考；不要改变它们的名字或语义。

## 验收顺序

1. 先在 CTRL 84–96 h 用原生交错笛卡尔网格验证 `u/v/th`：区域 RMS 残差除以端点状态倾向 RMS 和应不大于 0.2，同时报告空间相关和最优幅度比例。
2. 检查总项是否闭合；若总项闭合而分项不闭合，定位遗漏项或重复项，禁止把残差作为 eddy forcing。
3. CTRL 与 JET 分别通过后，才固定中心、做柱坐标变换和方位平均。
4. 再将经验证的热力、涡动、扩散与其他源分别映射到 SE RHS，并与状态直接诊断的 eddy-flux 路径交叉比较。

通过上述门槛只表示预算可用于定量诊断；SE 的平衡适用性、正则化敏感性和单对试验的因果局限仍须单独报告。
