# Thompson 240 h：加热位置的第一轮描述证据

本诊断使用 60、100、150、200 h 的 TC 中心坐标下 `ptb_mp + ptb_rad` 快照。正加热在 `r <= 300 km`、`z <= 20 km` 内，以圆柱体积权重及密度权重分别积分。这里的“加热总量”是输出时刻的空间积分，不是某个时段的累计能量，也不是闭合热力预算。

## 正非绝热加热的密度加权质心

| 时次 | CTRL 质心 (r, z) km | JET 质心 (r, z) km | JET−CTRL 加热积分 |
|---:|:---:|:---:|---:|
| 60 h | (87.6, 5.67) | (68.9, 5.81) | +7.9% |
| 100 h | (44.2, 5.33) | (30.1, 6.43) | +91.1% |
| 150 h | (35.2, 5.96) | (38.3, 6.00) | +2.5% |
| 200 h | (34.2, 5.99) | (37.0, 5.96) | +8.4% |

60 h 时 JET 的正加热比 CTRL 向内约 19 km；100 h 时仍向内约 14 km，且高约 1.1 km，并有明显更大的正加热积分。150 h 后，两组的加热位置和高度近似重合；200 h JET 反而略偏外。这不是“JET 始终加热更强”的模式，而是早期加热更内收、随后结构差异消退的模式。

这一发现为早期 JET 强度优势提供了一个可检验候选链条：更内侧的眼墙加热可能在相同或较小半径上有更高的平衡环流效率，进而有利于内核角动量和暖心发展。它还不能解释后期 JET 落后，因为 150–200 h 的快照没有显示出相反方向、同等清晰的加热位置差。

## 证据状态和下一步

- **描述事实**：表中的质心、积分和截面图直接来自已缓存的 CM1 输出。
- **尚未验证**：加热是否领先强度倾向、其对 SE 环流的响应效率是否更高、以及微物理快照是否可代表小时平均强迫。
- **下一项检验**：围绕 36–120 h 每 3 h 计算同一指标，并在固定 CTRL 算子下对正加热做守恒的小幅径向/垂直平移响应核；随后比较该响应与低层切向风倾向。完整热力 SE 强迫仍须等待高频累积预算的笛卡尔闭合。
